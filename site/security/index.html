Security boundary

STEWARD is a composition layer, not a replacement authority. Its public presence is intentionally unable to grant authority, create verification truth, or mutate canonical execution state.

Fail-closed invariants

  • canonical_truth=false
  • authority_effect=false
  • verification_effect=false
  • UI renderer failure falls back to static/text state.
  • succeeded requires a verification verdict.
  • verifying must originate from Sentinel verification state.

Canonical owners

AIE owns normative authority. Trust Gateway enforces policy. WORKS owns durable work. Runtime owns execution lifecycle. Sentinel independently verifies outcomes. Brand OS owns identity and visual grammar.

Source and disclosure

Security documentation and contract schemas are maintained in the canonical repository. Report implementation issues through the repository security process rather than treating this presentation surface as an authority endpoint.
