# STEWARD repository instructions

## Mission
Build the smallest compositional STEWARD reference system that can turn natural-language goals into inspectable, governed, persistent, independently verifiable outcomes.

## Non-negotiables
- Aftergraph is the master brand.
- Do not duplicate AIE, Trust Gateway, WORKS, Sentinel, Model Registry, Skills Vault, or governance ownership.
- Selected is not authorized.
- Predicted is not observed.
- Completed is not verified.
- Learned is not promoted.
- UI state is not canonical truth.
- Every consequential effect must be attributable to root intent, authority and exact Work.
- Every code verification verdict binds to an exact commit SHA.
- Worktrees isolate mutation; they do not create authority or independent evidence by themselves.

## Working method
1. Reconstruct actual state before editing.
2. Prefer contracts and adapters over duplicate services.
3. Use isolated Git worktrees for independent mutating work.
4. Preserve provenance and exact-subject identity.
5. Test against deterministic invariants or executable oracles where possible.
6. Treat LLM/Jev judgments as calibrated signals, not ground truth.
7. Record cost, latency, retries and human attention for meaningful experiments.
