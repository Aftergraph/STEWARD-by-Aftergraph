# Contributing

STEWARD changes should be small, evidence-linked and ownership-aware.

Before proposing a component:
1. Search Aftergraph repositories for an existing owner.
2. Search external prior art when novelty is implied.
3. State the contract and canonical truth owner.
4. State failure, recovery and invalidation semantics.
5. State measurable cost/latency/context overhead.
6. Add or update conformance tests when changing a contract.

Architectural changes require an ADR under `adr/`.
