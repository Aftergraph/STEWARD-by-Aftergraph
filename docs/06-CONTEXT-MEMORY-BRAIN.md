# Context, Memory and Brain Contract v0.1

## Memory hierarchy
- L0 turn/prompt state
- L1 THREAD working set
- L2 Session/runtime checkpoints
- L3 Project memory/context continuity
- L4 CHRONICLE episodic trajectories
- L5 PROFILE/topic semantic memory
- L6 BRAIN promoted semantic knowledge
- L7 SKILLS procedural memory
- L8 artifact/evidence/execution history

## Read path
Intent/Mission → RECALL → candidate memories/sources → VERITY → ranking by relevance/freshness/scope/provenance/privacy → FRAME → REASON.

## Write path
Observation/trajectory → CHRONICLE episode → CONSOLIDATE → candidate topic/profile/Brain/Skill changes → policy/evidence/bench → promotion.

## Precedence heuristic
Current observation > current explicit instruction > current Mission/Project state > verified promoted knowledge > semantic memory > episodic recall > old summary.

This is a heuristic, not authority precedence; platform policy and authority remain separate.

## Consolidation
Consolidation may cluster, summarize, deduplicate, identify contradictions, supersede stale facts and propose forgetting. It does not validate truth by itself.

## Forgetting
Model irrelevance is not deletion authority. Retention/deletion obey custody, principal rights and organizational policy.

## Context optimization
Working context is selected under a budget. Relevance, freshness, provenance and verification increase value; redundancy and token cost decrease it.

Compression preserves source references. Exact/high-impact decisions should rehydrate original source material rather than rely only on summaries.
