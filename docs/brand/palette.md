# STEWARD palette — "Custody & Cream"

| Name | Hex | Role |
|---|---|---|
| Cream | `#FAF6EF` | Paper / background |
| Warm Ink | `#1E1B16` | Text / line / outline |
| Steward Copper | `#C2703D` | Primary accent |
| Pine Teal | `#23615E` | Verification semantics |
| Moss | `#3E7C59` | Success / verified |
| Muted | `#6B665C` | Secondary text |
| Night | `#0B1120` | Dark surfaces (characters/UI) |

Usage proportions: ~50% paper, ~25% ink, ~15% copper, ~10% teal/moss.
Semantics: teal = verification, moss = approval/success, amber `#E0A93B` = caution/waiting, red `#E5484D` = blocked/failed.
Dark mode: background `#17130E` (paper), text `#FAF6EF`, borders `#2A3A5C`.
