# STEWARD Charter and Scope v0.1

## Definition
STEWARD is Aftergraph's persistent, multimodal, project-aware intelligence system that coordinates cognition, people, agents, tools and computers while preserving external ownership of authority, durable execution truth and independent verification.

## Product promise
A user should be able to state a goal conversationally, inspect what STEWARD understood, delegate bounded work, steer it while it runs, receive only meaningful interruptions, and obtain artifacts or real-world effects whose completion is independently supportable.

## Core responsibilities
STEWARD owns composition and user-facing intelligence behavior:
- interaction and project workspace semantics;
- context assembly, recall and retrieval orchestration;
- cognitive routing and planning;
- multi-agent composition and coordination;
- harness selection and environment requirements;
- integration with authority, execution and verification owners;
- proactive routines, suggestions and human attention policy;
- learning candidates and governed improvement flow.

## Explicit non-ownership
STEWARD does not become the canonical source of:
- normative authority or delegation — AIE owns it;
- policy enforcement, approvals, secrets or egress — Trust Gateway owns it;
- attempts, leases, checkpoints, external-effect dispatch or execution truth — WORKS owns it;
- independent exact-subject verdicts — Sentinel owns them;
- model or skill registry truth — their registries own them.

## Primary system law
Models, agents, memory, simulations and learned policies may propose or select among already permissible options. They may never create permission by themselves.

## Success condition
A Mission succeeds only when its acceptance criteria are met by sufficient evidence and required verification, not when an agent reports completion.
