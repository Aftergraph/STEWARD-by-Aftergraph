# Security

STEWARD assumes hostile or fallible models, tools, connectors, webpages, files and delegated agents.

Security boundaries:
- cognition may propose but not mint authority;
- credentials are brokered, scoped and short-lived;
- network reachability does not imply allowed egress;
- external effects use typed contracts, idempotency where possible, receipts and readback;
- child delegation cannot widen parent authority;
- project/context files cannot override platform authority or safety policy;
- secrets must not be committed to this repository.

Report security issues through the private Aftergraph security channel rather than public issues when disclosure would increase risk.
